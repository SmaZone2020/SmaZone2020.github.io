## 简介

douyin.js 是一个运行在浏览器控制台的轻量 SDK，用于自动化抖音网页版聊天（`douyin.com/chat`）。无需后端、无需安装，注入脚本即可使用。

项目地址：[GitHub](https://github.com/SmaZone2020/douyin-web-chat)

## 能做什么

- 监听收到的消息（文本、图片、视频分享、评论分享）
- 发送文本消息，支持换行和分条
- 发送普通小表情和超级表情
- 获取分享视频的 mp4 直链
- 切换聊天对象、监控未读消息
- 上传图片/视频文件

## 快速开始

1. 打开 `https://www.douyin.com/chat?isPopup=1`
2. 打开浏览器控制台（F12）
3. 粘贴 `douyin.js` 全部代码并回车

```javascript
// 监听消息并自动回复
DouyinSDK.on("message", async (msg) => {
    if (msg.text === "在吗") {
        await DouyinSDK.sendTextMsg("在的，请问有什么可以帮您？");
    }
});
```

## 核心功能

### 消息监听

支持解析多种消息类型：

| 类型   | 字段                             |
| ---- | ------------------------------ |
| 文本   | `msg.text`                     |
| 图片   | `msg.images[]` — src、宽高        |
| 视频分享 | `msg.videos[]` — 封面、作者、头像      |
| 评论分享 | `msg.comments[]` — 评论者、内容、来源视频 |

### 视频直链获取

收到视频分享后，可通过拦截网络请求自动获取 mp4 直链：

```javascript
const { url, error } = await DouyinSDK.fetchVideoUrl(msg.videos[0].element);
```

SDK 会自动点击视频 → 监听 `douyinvod.com` 请求 → 获取直链 → 关闭弹窗。

### 发送消息

```javascript
// 单条换行
await DouyinSDK.sendTextMsg("第一行\n第二行");

// 分多条发送
await DouyinSDK.sendTextMsg("第一条\n\n第二条");
```

## 适用场景

- 接入 AI Bot，让大模型自动回复抖音私信
- 自动续火花
- 消息监控和转发
- 批量回复

## 技术实现

- 通过 Slate 编辑器的 `ClipboardEvent` 模拟粘贴输入
- 通过 `PerformanceObserver` + XHR/Fetch 拦截获取视频直链
- 通过 `MutationObserver` 监听 DOM 变化检测新消息和 Toast 提示
